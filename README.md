# ai-guides

유튜브 영상에서 직접 해 본 AI 활용법을 따라 할 수 있게 정리한 곳입니다.
영상에서 쓴 프롬프트, 명령어, 스크립트를 에피소드별 폴더에 그대로 올려 둡니다.

## 쓰는 법

1. 보고 온 영상의 에피소드 폴더를 엽니다.
2. 폴더의 README에 있는 준비물부터 확인합니다.
3. 프롬프트와 명령어를 순서대로 복사해 실행합니다.

## 폴더 구성

에피소드마다 이렇게 구성합니다.

- `README.md`: 준비물, 순서, 실제로 된 것과 안 된 것
- `prompts/`: AI에게 보낸 프롬프트 원문
- `scripts/`: 영상에서 쓴 명령어와 스크립트
- `troubleshooting.md`: 막혔던 지점과 우회한 방법
